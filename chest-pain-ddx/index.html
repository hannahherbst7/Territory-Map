Chest Pain Differential

Enter the symptom pattern and the engine works the way ED triage does: it screens for dangerous patterns first, then ranks the remaining causes by how many classic features match.

For educational use only. This tool is a learning reference, not a medical device, and is not a substitute for professional medical evaluation. If someone is having concerning chest pain right now, call 911.

Feature profiles, urgency levels, and confirming tests follow standard clinical teaching on classic presentations and live in conditions.js — edit that file to tune the logic or add conditions. Scoring is simple relevance matching: matched classic features ÷ total features, minus features that point away. v1 covers 8 conditions; red-flag screening also watches for cardiac tamponade.
